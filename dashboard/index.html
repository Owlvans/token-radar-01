Implied value is what the token would be worth if the protocol launched one on the snapshot's record. It is not a prediction that a token will launch, or when. Click a row for the full pricing breakdown and its farm plan.

These protocols already have a token that trades, so the radar never ranks them: the market has priced them itself. They are the reference set — the evidence the model prices the pre-token board from. Each row shows the market's own figures and the market-cap/TVL ratio the model reads.
