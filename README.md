# token-radar-01

A judged "token radar" board entry. `main.ts` and `lib/model.ts` turn a snapshot of token data into a ranked, filterable board (`dashboard/` holds the static board UI) and build the submission dossier from it. Node 22, standard library only.

Status: v1 standing entry; result due 2026-12-28.

Note: the competition-provided vendored harness under `vendor/` is third-party code and is not included in this mirror.

Note: the board screenshots (JPEG) are not included in this repository because the upload channel used here is text-only.
